## Инструкция
Учебная практика. Бикмухаметов, Бадасян, Бушуев

## Консольная утилита для пакетной конвертации учебных файлов между форматами (.txt .json).

## Зачем это нужно?
При переносе учебных данных (тестов, вопросов, конфигураций) между LMS (Moodle, Canvas, Stepik и др.) часто возникает проблема несовместимости форматов. Ручное переформатирование отнимает часы и приводит к ошибкам разметки (потеря вложенности, лишние запятые, битые строки).
Автоматизация: один проход по папке — и все файлы конвертированы.
Безопасность: режим dry-run позволяет проверить корректность данных без перезаписи файлов.
Гибкость: поддержка разных кодировок (UTF-8, CP1251) и шаблонов парсинга.
Интеграция: понятные коды выхода (exit codes) для использования в CI/CD пайплайнах.

## Возможности
Конвертация .txt - .json и .json -.txt.
Пакетная обработка директорий с сохранением структуры подпапок.
Валидация данных: утилита не падает на битом файле, а собирает отчет об ошибках.
Поддержка регулярных выражений для кастомного парсинга строк.
Форматированный вывод JSON (pretty-print) или компактный режим.
